# Ticket Scanning

This guide is for event staff who check people in at the door.

## Scan a ticket
1. Sign in to Aldriva.
2. Open the scanner for the correct event.
3. Allow camera access if your device asks for it.
4. Point the camera at the attendee's QR code.
5. Wait while Aldriva verifies the ticket.
6. Follow the result shown on screen.

If the camera is unavailable, you can enter the ticket code manually.

## Scan results
| Result | Meaning |
| --- | --- |
| Accepted | The ticket is valid for this event and has not been checked in yet. |
| Already checked in | The ticket has already been used for entry. |
| Wrong event | The ticket belongs to a different event. |
| Ticket cancelled | The ticket was cancelled. |
| Ticket refunded | The ticket was refunded. |
| Invalid ticket | The code could not be verified. |

## After a scan
After a result appears, the scanner resets automatically so the next guest can be scanned.

You can also tap **Scan Next** to clear the result immediately.

## Important limits
- Offline scanning is not currently available
- The scanner needs a live connection to verify tickets
- Re-entry tracking is not currently available
