# Refunds and Cancellations

This guide only covers refund and cancellation behavior that is currently supported by the product.

## Ticket cancellation
If a ticket is cancelled, it is rejected at check-in.

## Ticket refund
If a ticket is refunded, it is rejected at check-in.

## Already-used tickets
A ticket that has already been checked in cannot be checked in again.

A used ticket cannot be refunded through the protected refund flow.

## Event cancellation
Some event pages may include a refund policy written by the organizer.

Beyond that, the public product does not define a single global refund deadline, automatic refund rule, or organizer refund policy.

If you need a refund, follow the event's stated policy or contact the organizer.
