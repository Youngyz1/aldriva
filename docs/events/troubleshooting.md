# Troubleshooting

## I bought a ticket but cannot find it
Try these steps:
1. Open [My Tickets](./my-tickets.md)
2. Sign in with the account you used during purchase
3. If you checked out as a guest, use **Guest Order Lookup**
4. Enter the order ID or QR reference and the email used at purchase
5. Check your confirmation email for the ticket pass link

## My QR code is not scanning
Try these steps:
1. Brighten the screen
2. Make the QR code fill more of the screen
3. Clean the camera lens
4. Hold the phone steady
5. Open the ticket pass and try again
6. If needed, use manual code entry on the scanner

## The scanner says my ticket was already used
That ticket has already been checked in.

If you bought multiple tickets, use the correct QR code for the ticket that has not been used yet.

## The scanner says my ticket belongs to another event
That ticket was purchased for a different event and cannot be used to enter the current one.

## I bought multiple tickets
Each ticket has its own QR code.

If you bought five tickets, you should have five separate ticket passes.

## My staff member cannot access the scanner
Check the following:
1. They are signed in to Aldriva
2. They accepted the invitation with the same email address it was sent to
3. They were invited as **Ticket Scanner** or **Event Manager**
4. The invitation was not cancelled
5. The invitation has not expired

If the invite was removed or expired, send a new invitation.

## Offline scanning is not working
Offline scanning is not currently available. The scanner needs a live connection to verify tickets.
